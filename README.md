## 3-D model

[`MECHANICAL/M568P.stl`](MECHANICAL/M568P.stl) (GitHub turns it in 3-D) · [view, change and generate it on WBSps.ca](https://wardbecksystems.github.io/WBSps.ca/2026/stl.html?m=M568P)

- **Size:** 56.13 × 219.35 mm panel, 165 mm deep, 3.2 mm plate (the drawing sheet, taken as drawn 1:1)
- **From the drawing:** 14 holes and cut-outs, 1 knobs (front panel: `MECHANICAL/M568P - front panel.svg`)
- the drawn panel is 0.22 wide to high, the size 0.26: placed by its height
- Made by `tools/module_models.py` (→ `MECHANICAL/M568P.model.json`) and `tools/stl/make_stl.mjs` in [WBSps.ca](https://github.com/WardBeckSystems/WBSps.ca); the site makes the same STL from the same JSON.
